# VC-1 本机验证（2026-10-11）

本机 Apple M1 Max，macOS arm64；上游起点 `51512f1`，GGML `2eddaf94`。
使用可分发 ARM 基线构建（完整命令见同目录接入文档），实际后端注册表 `MTL`、设备 `MTL0`。
模型为调研中的 0.6B-Base Q8_0 与 tokenizer Q8_0，不提交权重。
沿用调研的 FLEURS female 参考录音，解码为 24kHz 单声道 f32，经真实 `qt_extract_voice_ref`
现场提取，再固定同一份声纹、int32 RVQ 码与参考文本；seed 恒为 42。

## 有界验证结果

- 新增 C99 后端测试先红：头文件缺 `n_threads`、`backend`、查询与枚举接口，退出码 1。
- Metal 动态库与上游 C99、后端专项编译通过；默认 CTest 两项通过，退出码 0。
- 纯 CPU 构建的相同 CTest 两项通过，退出码 0；不依赖 GPU 存在。
- `python3 -m unittest discover -s tests -p 'test_build_plan.py'`：6 项通过，退出码 0。
- 两个 POSIX 平台入口 `sh -n` 通过；Windows/Linux 仅核对构建计划，未真机构建，未发包。
- E2E 未运行；本片只做引擎有界专项。
